The local previews start at macOS sign-in and restart automatically if they exit. They run independently of Codex while the Mac is awake. Port 3004 serves a separately maintained local V2 build. The V2 baseline on port 3006 and the original Ready UI on port 3007 each use their own local database.

Port 3008 runs under the `com.zerotrust.ready-ui-audit-preview` login service. The installed preview lives in `~/Library/Application Support/ZeroTrust/Ready UI Audit`, with its database in `data/`. The original database remains in `.local-preview/mvp-ready-audit-data` as a rollback copy.

To refresh the installed UI, run `npm run build:local` in the checkpoint worktree, sync `dist/` to the installed `site/` directory, then copy the generated `full-mvp/index.html` and `full-mvp/stakeholder/index.html` to their matching paths. Copy `full-mvp/service.py` and restart the login service if the server code changes.
